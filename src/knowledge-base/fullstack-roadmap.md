# 全栈与 AI 开发学习路线

这个知识库围绕“全栈工程能力 + AI 应用开发能力”整理，目标是让简历站不仅展示项目，也展示持续学习、全链路思考和面向未来的软件开发判断。

## 能力结构

| 层级 | 核心内容 | 求职价值 |
| --- | --- | --- |
| 前端基础 | HTML、CSS、JavaScript、TypeScript | 保证页面质量、交互体验和代码可维护性 |
| 前端框架 | Vue2、Vue3、Vite、组件化、状态管理 | 支撑中后台、小程序 H5、SaaS 平台开发 |
| 后端服务 | Java、Spring Boot、Python、FastAPI | 能参与接口设计、业务逻辑、权限和联调 |
| 数据库 | MySQL、SQL、索引、事务、Redis | 理解业务数据流转和性能瓶颈 |
| 工程化 | Git、Nginx、Docker、构建部署、日志排查 | 能把项目稳定发布到测试和线上环境 |
| AI 应用 | 大模型 API、Prompt、AI Agent、RAG、向量检索 | 把智能问答、文档解析、内容生成和数据分析接入业务系统 |

## 推荐阅读顺序

1. JavaScript 与 TypeScript：夯实语言基础，写出稳定可维护的前端代码。
2. HTML/CSS：掌握布局、兼容性、动画和滚动容器等页面细节。
3. 前端架构：理解抽象、组件边界、设计模式和业务复用。
4. Java 与 Spring Boot：建立服务端分层、事务、权限和接口意识。
5. Python 与 FastAPI：补充快速开发接口、脚本工具和数据处理能力。
6. 数据库与 SQL：掌握表结构、索引、分页、事务和常见业务模型。
7. 接口设计与工程化：形成从需求、页面、接口、数据到发布的完整链路。
8. 部署、Nginx 与 Docker：掌握基础上线、代理、日志和回滚能力。
9. AI 应用开发：学习大模型 API、Prompt、RAG、Agent、向量检索和业务系统集成。

## AI 开发与未来趋势

AI 不只是一个单独功能，而会逐步成为业务系统的基础能力。未来的企业级应用会从传统的“表单、列表、审批、报表”升级为“数据中台 + 业务流程 + AI 助手”的组合。

值得重点关注的方向：

- 智能问答：把企业制度、项目文档、接口文档、数据字典做成可检索的知识库。
- 文档解析：自动提取合同、招标文件、采购要求、简历、报告中的关键信息。
- 数据分析助手：让用户用自然语言查询业务数据，辅助生成报表和分析结论。
- 代码辅助：使用 AI 提升需求拆解、代码生成、测试用例、问题排查和文档编写效率。
- 流程自动化：通过 Agent 串联查询、判断、生成、审批、通知等多步业务动作。
- 数据中台智能化：在数据资产、数据标准、数据服务、运行监控中加入 AI 解释和辅助决策能力。

全栈工程师在这个趋势下的价值会更明显：既能理解业务流程和数据结构，也能把 AI 能力稳定接入前端页面、后端接口、数据库和部署环境。

## 简历表达重点

全栈岗位最看重的是“能把业务跑通”。可以从这些角度组织表达：

- 前端：页面开发、组件封装、状态管理、性能优化、权限菜单、表单列表。
- 后端：RESTful API、统一响应、参数校验、错误码、JWT、角色权限。
- 数据：MySQL 表结构、索引、事务、分页查询、状态流转、操作日志。
- AI：Prompt、RAG、向量检索、文档解析、智能问答、数据分析助手。
- 交付：接口联调、测试环境发布、Nginx 代理、构建部署、线上排障。
- 协作：能和产品、设计、后端、测试对齐字段、流程和验收标准。

## 项目复盘模板

每个项目都可以按以下方式复盘：

```text
项目背景
  -> 业务角色
  -> 核心流程
  -> 页面模块
  -> 接口模块
  -> 数据状态
  -> 权限边界
  -> 性能与异常
  -> 上线结果
```

这种复盘方式能让项目经历从“我做了页面”升级为“我理解业务并完成了端到端交付”。
